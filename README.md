# Hi, I'm Rajul Firas

**Software Engineer | System Designer**

I help companies with the development, integration, maintenance, and scaling of their proprietary software.

How I work

Every project starts with understanding the **why** — the business goal, the constraints, the trade-offs. From there, I design and calculate each part of the system, then document every decision in an **ADR (Architecture Decision Record)** so nothing is a black box.

I use AI to move fast, but I verify every part against my own engineering standards — architecture, security, cost, business, performance, testing, production readiness, and monitoring.

> _AI accelerates the typing. I own the decisions._

## Featured Projects

### Chemtial — B2B/B2C Chemical & Laboratory E-Commerce

A production-oriented fullstack e-commerce platform with Clean Architecture, dual order workflow (online payment + COD), and multi-language support (6 languages).

- **Architecture:** Clean Architecture (Domain → Application → Infrastructure → Presentation)
- **Payments:** Stripe (checkout sessions + webhooks)
- **Security:** JWT + refresh token rotation, RBAC (4 roles), 6-tier rate limiting, Helmet CSP, CORS whitelist, audit logging
- **Scale:** $0 infrastructure cost at MVP, with documented 4-stage scaling roadmap to ~$59/month

[Live Demo](https://chemtial.vercel.app) · [Source Code](https://github.com/RAJULFIRAS/chemtial)

---

### Natarsal — Restaurant Reservation Platform

A fullstack restaurant reservation platform with ACID-safe lifecycle, role-based access, and production hardening.

- **Lifecycle:** PENDING → CONFIRMED → COMPLETED/CANCELLED/NO_SHOW
- **Security:** JWT + refresh token rotation, RBAC (USER/ADMIN), Zod validation
- **Deployment:** Vercel serverless functions, PostgreSQL (Neon), Vercel Blob
- **Scale:** $0 infrastructure cost at MVP, with documented upgrade path

[Live Demo](https://natarsal.vercel.app) · [Source Code](https://github.com/RAJULFIRAS/natarsal)
